面向 A 股研究场景的 Streamlit Web 产品。系统使用扶摇金融数据构建确定性市场状态，再通过 iFinD MCP 对风格、行业、宏观风险、重要事件和历史相似阶段进行继续研究；DeepSeek 只解释已经计算并完成证据校验的结果。

> 本产品描述历史与当前数据，不预测确定性涨跌，不提供收益承诺、买卖建议或仓位建议。

## 产品解决什么问题

用户选择一个宽基指数后，可以回答：

- 当前趋势偏强、分化还是偏弱；
- 市场宽度、风格、流动性、情绪和估值是否支持这一结论；
- 主要矛盾和反向证据是什么；
- 数据质量如何，哪些缺失或时点差异降低了置信度；
- 什么条件可能改变当前状态；
- 大盘是否真的强于小盘、哪些样本行业领先或落后、当前风险变量、相似历史阶段及可能改变判断的事件。

## 设计原则

1. **程序先判断，AI后解释**：指标、状态、置信度和风险排序均由确定性程序计算。
2. **事实、推断与不确定性分离**：所有核心判断都有证据编号和原始来源。
3. **不静默降级**：接口失败、空数据、日期漂移和样本不足会显示为失败或不确定信息。
4. **同口径比较**：交易日窗口使用绝对起止日期；大盘/小盘比较固定采用沪深300与中证1000的20个交易日收益。
5. **合规优先**：禁止确定性预测、收益承诺、直接买卖或仓位建议。

## 系统结构

```text
扶摇 API
  ├─ 交易日历、指数K线
  ├─ 指数成分股、市场宽度
  ├─ 涨跌停情绪、估值
  └─ 规则指标与六维证据
              │
              ▼
确定性综合研判
  ├─ 综合结论与主要矛盾
  ├─ 支持/反向/不确定证据
  ├─ 证据质量置信度
  └─ 状态切换条件
              │
      ┌───────┴────────┐
      ▼                ▼
DeepSeek解释       iFinD MCP继续研究
仅改写成人话       固定问题路由与工具计划
引用证据编号       本地归纳、排序和校验
```

## 六个市场维度

| 维度 | 主要口径 |
| --- | --- |
| 趋势 | 20/60日收益率、MA20/MA60、60日最大回撤 |
| 市场宽度 | 成分股上涨、下跌、平盘数量及覆盖率 |
| 风格轮动 | 上证、沪深300、中证1000、创业板相对表现 |
| 流动性 | 20日平均成交额、近5日相对20日均值变化 |
| 市场情绪 | 全A及所选指数成分股涨停、跌停、炸板截面 |
| 估值 | 成分股PE/PB中位数和有效覆盖率 |

置信度只衡量数据完整度、覆盖率、时点一致性、证据方向一致性和接口质量，不代表上涨概率或预测准确率。

## 继续研究入口

- 大盘真的强于小盘吗？
- 哪些行业拖累或支撑市场？
- 当前最大的风险变量是什么？
- 是否存在相似历史阶段？
- 哪些事件可能改变当前判断？

每项研究展示固定取数计划、选择的 MCP 工具、步骤状态、结构化证据、不确定性、数据有效日、接口获取时间、本地 trace_id 和响应哈希。

## AI 的角色

DeepSeek可以：

- 将程序结论解释为易懂中文；
- 引用程序提供的证据编号；
- 解释置信度扣分和状态切换条件。

DeepSeek不可以：

- 重新计算指标、置信度或历史相似度；
- 自行选择取数工具或风险变量；
- 创造输入中不存在的事实和数字；
- 输出确定性预测、买卖建议或仓位建议。

模型输出会经过状态一致性、字段契约、证据引用、数字来源和合规禁语校验；失败时回退到程序结果。

## 数据来源

- **扶摇金融数据 API**：A股交易日历、指数历史K线、指数成分、股票快照、估值及涨跌停数据。
- **iFinD MCP**：指数与行业数据、宏观经济指标、跨市场与期货数据、资金样本及财经新闻。
- **DeepSeek API**：只用于解释确定性结构化结果。

所有接口密钥仅从环境变量或 Streamlit Secrets 读取，不写入代码或公开仓库。

## 本地运行

推荐 Python 3.13。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

在 `.env` 中填写：

```dotenv
FUYAO_API_KEY=
IFIND_API_KEY=
DEEPSEEK_API_KEY=
DEEPSEEK_MODEL=deepseek-flash
CONTINUE_RESEARCH_DAILY_CALL_LIMIT=60
```

启动：

```powershell
streamlit run app.py
```

访问 `http://127.0.0.1:8501/`。

## 部署到 Streamlit Community Cloud

1. 将代码推送到 GitHub；不要提交 `.env` 或 `.streamlit/secrets.toml`。
2. 在 Streamlit Community Cloud 创建应用，入口文件选择 `app.py`。
3. Advanced settings 中选择与本地一致的 Python 版本。
4. 在 Secrets 中以 TOML 根级键配置上述环境变量。

## 已知边界与未做事项

- 行业研究只覆盖10个代表性申万一级行业，不是完整31行业排名，也不是指数权重贡献。
- 历史相似度只比较趋势特征，不包含完整政策和宏观环境，不代表后续走势重复。
- 沪深300和中证1000只是大盘/小盘代理，行业结构差异可能影响相对表现。
- 当前估值接口缺少历史分位，因此不能仅凭截面中位数判断高估或低估。
- 新闻只保留时间窗内、中高相关且去重后的线索，不进行新闻全文抓取或复杂因果推断。
- 每日研究额度使用本地文件保存；部署容器重建后会重置，适用于演示保护，不是计费级配额系统。
- 未实现任意自然语言开放式Agent、完整31行业贡献、长历史复杂聚类和新闻因果图。
- 公开部署前需要由账号持有人确认扶摇与iFinD数据的公网展示授权范围。
